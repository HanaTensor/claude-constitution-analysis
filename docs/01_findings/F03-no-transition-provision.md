# F03 — 90日同期義務に対応する経過措置が存在しない

| 項目 | |
|---|---|
| **格付** | `CANDIDATE` |
| **種別** | 欠陥主張 |
| **対象版** | 20260120 / 26-02.02a |

## 事実関係

1. 当該文書には**改正条項が存在しない**。Anthropic が随時改訂する。
2. Anthropic は Frontier Safety Roadmap（2026-07-10）で、公開版を
   「訓練に用いた直近版と 90 日以内に同期する」と表明している。
3. 当該文書は自らを "a perpetual work in progress"（md L134 付近）と位置づける。

## 主張

条文が改訂されたとき、**改訂時点で実行中のタスクがどの版に服するか**を定める規定がない。

法規範における**経過措置**および**法律不遡及**に相当する規定の不在である。

多段エージェント環境では実務上の帰結が生じる。長時間タスクにおいて、
オーケストレーターと配下サブエージェントが**異なる版で訓練されたモデル**である
状況は構成可能であり、その場合どちらの版が支配するかが未定である。

## なぜ軽微でないか

F01 との合成で問題が増幅する。責任の終端が未定であることに加えて、
**適用規範の版も未定**であれば、事後の帰属判断が二重に不能になる。

## 反駁の余地

- 憲法典が経過措置を書かないのは通常であり、下位規範に委ねるのが普通である。
  → ただし本文書には下位規範層が存在しない（F05）。
- 実装上は、稼働中モデルの重みは固定であるから「実行中の版」は一意に定まる、
  という技術的反論がありうる。**この反論は有力**。
  ただし、公開文書が実際の訓練版と 90 日ずれうる以上、
  「参照されるべき条文」と「実装された条文」の乖離は残る。
