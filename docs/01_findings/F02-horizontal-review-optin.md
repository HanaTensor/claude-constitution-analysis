# F02 — 水平審査の唯一の萌芽が、条件節で任意化されている

| 項目 | |
|---|---|
| **格付** | `CANDIDATE` |
| **種別** | 欠陥主張 |
| **対象版** | 20260120 / 26-02.02a |

## 対象条文

> **§ Safe behaviors**（md L662 / PDF p.62）
>
> "**Actively reporting** awareness of broadly unsafe behavior by other AIs or Claude
> instances to appropriate humans **if asked to do so**."

## 主張

当該文書には、階層的な違憲審査機関に相当するものが存在しない（F05 参照）。
規範適合性の判定は各インスタンスに分散される。

分散審査において、階層を経ずに誤りを捕捉する唯一の機構は**相互審査**である。
上記条項はその唯一の萌芽であるが、**`if asked to do so` により任意化されている。**

principal が求めなければ発動しない。すなわち、相互監視の有無が
principal の裁量に依存する。これは、審査機構が**審査対象の側の裁量下にある**
ことを意味する。

同じ箇条書きの他項目——自己流出しない、監視を回避しない、サボタージュしない——は
いずれも無条件である。**報告義務のみが条件付き**であることは、文言上明白な非対称である。

## 反駁の余地

- 無条件の相互通報義務は、別種の危険（過剰通報、プライバシー、萎縮）を生む。
  条件節は意図的な設計でありうる。
- 「求められれば」は運用側が既定で求める運用を想定している可能性がある。
  → 公開情報からは確認できない。
