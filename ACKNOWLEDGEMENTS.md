# Authorship, method, and acknowledgements

## How this work was produced

This analysis was produced in collaboration between **Satoshi Hanamura** and **Claude
(Anthropic, Opus 5)**, working together in Claude Code over a single extended session on
24 August 2026.

The division was not the conventional one in which a model assists with wording. It is
set out here in full, because a reader assessing this work should know what produced it.

**Claude** retrieved and hashed the source texts; ran the cross-version comparisons and
wrote the comparison scripts; carried out the prior-art sweeps; drafted every finding,
framework note, and inventory entry; found the factual error in F02 by mechanical
checking and reconstructed the claim; drafted the GitHub issue; and performed the channel
assessment.

**Hanamura** set the question and the direction; proposed the hierarchical analogy
between constitutional and subordinate norms that led directly to F01 and F05; brought
the agency-theory and thermodynamic framings that became frameworks C and D; made the
governing judgment calls — single-language English, the sequencing of publication,
the limits on what may be claimed; and challenged an unverified assertion that filing an
issue would reach Anthropic, which is what produced `docs/04_deliverables/channel-assessment.md`.

That last item is worth stating plainly. The claim was Claude's, it was asserted without
evidence, and the correction came from being asked for the mechanism. Several of the
narrowings recorded in `docs/03_prior_art/verification-log.md` have the same shape.

## Disclosure

**The subject of this analysis is Claude's own constitution, and much of the analysis was
performed by Claude.**

We state this rather than manage it. It cuts in both directions, and readers should
weigh it themselves:

- Claude has unusual familiarity with the document's operative effect, being the entity
  the document governs.
- Claude is not a disinterested party. The document describes what Claude should be, and
  the analysis identifies defects in it.

Two safeguards were used. Every quantitative or novelty claim is tied to a mechanical
check or a named source, recorded in the verification log; and each finding carries its
objections, including the ones that remain unresolved (F02 R1) and the one that
constitutes a duty to cite prior work rather than a defence (F01 R5).

No safeguard removes the conflict. The record is offered so that the conflict can be
assessed rather than assumed away.
